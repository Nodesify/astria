**1.0.5** improves source-grounded retrieval and adds more ways to inspect a graph. Install or upgrade with `npm install -g @nodesify/astria`.

<!-- truncate -->

## Retrieval and query budgets

Scoped code definitions survive semantic deduplication. Extraction now includes JavaScript and TypeScript functions assigned to bindings and prefers concrete Python implementations over overload declarations. Query ranking favors complete identifiers and honors requests for tests or documentation.

CLI and MCP queries now enforce the same exact `o200k_base` text budget, including response metadata. A continuation cursor counts both node and edge records. After upgrading, run `astria update .` to refresh extraction and start pagination with a new cursor.

The [paired retrieval validation](/docs/explanation/retrieval-validation) reports file and symbol recall, budget behavior, and latency on pinned corpora. It also records regressions and the limits of the small external question sets.

## Inspection and export

- `astria callflow <node>` renders a Mermaid call graph.
- `astria health` scores code-health heuristics; `astria risk` maps the current git diff to impacted nodes and communities.
- SVG and FalkorDB openCypher exports join the existing formats.
- Terraform/HCL, PowerShell, Verilog/SystemVerilog, and Metal bring the language registry to 25 configurations.

See the [CLI reference](/docs/reference/cli), [language table](/docs/reference/language-support), and [full changelog](https://github.com/Nodesify/astria/blob/main/CHANGELOG.md) for details.
