**1.0.9** is the distribution release: astria is now listed where agents and package managers look for it — the official MCP Registry, the Claude Code plugin marketplace, Homebrew, and Smithery. Install or upgrade with `npm install -g @nodesify/astria`.

<!-- truncate -->

## Official MCP Registry

The repo now carries a registry `server.json` (`io.github.Nodesify/astria`, stdio transport over the npm package), and `release.yml` publishes it via `mcp-publisher` with GitHub OIDC after the npm publishes succeed. The `verify` job fails fast when `server.json`'s version drifts from the package version, and npm packages declare the matching `mcpName` the registry validates.

## One plugin for Claude Code

`/plugin marketplace add Nodesify/astria` then `/plugin install astria@nodesify` wires everything in one step: the MCP server, the graph-first skill, `/astria` and `/astria-risk` slash commands, and an `astria-architect` subagent.

## Homebrew and Smithery

- `brew install nodesify/tap/astria` installs the published npm package — prebuilt native binaries, no Rust toolchain. The formula lives in the [`Nodesify/homebrew-tap`](https://github.com/Nodesify/homebrew-tap) repo.
- `smithery.yaml` describes the stdio start command over the published npm package, so smithery.ai can list the server once the repo is connected there.
