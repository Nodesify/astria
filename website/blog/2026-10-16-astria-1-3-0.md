**1.3.0** adds TypeScript receiver resolution through declared types and inherited members, interface dispatch relationships, and project-aware imports. These bindings retain their evidence class: source-derived resolution is not proof of runtime behavior.

<!-- truncate -->

Explicit query seeds anchor traversal at known symbols. TypeScript path aliases, workspace package entries, and scoped subpaths resolve to authored source files. Interface members link to possible implementing classes through inferred dispatch relationships.

Per-file extraction status distinguishes complete, partial, unsupported, skipped, and suspiciously empty files. Evidence-weighted clustering, actionable memory, grammar-aware caches, project language overrides, stable community labels, and a post-merge hook round out the release.

The [1.3.0 changelog](https://github.com/Nodesify/astria/blob/v1.3.0/CHANGELOG.md) records the full changes and measured evaluation scope. Follow the [retrieval validation documentation](/docs/explanation/retrieval-validation) for methodology and limitations.
