**1.5.0** explains how query nodes enter an answer, makes refresh recommendations actionable, and improves downstream evaluation reporting. Check the [GitHub release](https://github.com/Nodesify/astria/releases/tag/v1.5.0) for publication status.

<!-- truncate -->

## Understand a retrieved result

Rendered query nodes include a retrieval reason; structured CLI and MCP nodes expose `retrievalReason`. Reasons distinguish query relevance, graph neighbors, and unresolved endpoints. They describe selection evidence rather than a calibrated correctness probability. At equal relevance and traversal distance, located code declarations precede file hubs unless file preference is requested.

Relationship confidence remains separate from retrieval relevance. Verify important behavior against the cited source; missing relationships cannot establish the absence of runtime dependencies. These changes do not establish a measured improvement in completed coding tasks.

## Follow a complete investigation

The getting-started guide now connects structural indexing, querying, explaining a node, assessing affected consumers, and refreshing after edits. `astria status --json` includes `recommendations`; stale compiler indexes need regeneration and reimport with `astria add --scip <index-file>`, even after a structural update.

## Report only supported task comparisons

Downstream task reports identify why a pair is not comparable, including unfinished runs, unverified runtimes, revision mismatches, and missing correctness reviews. Aggregate measurements count missing or noncomparable pairs without treating them as zero savings. The reporting changes do not run agents or produce new task-quality evidence.

## Upgrade

This release also updates vulnerable spreadsheet/archive/compression dependencies, Tokio, and a yanked cryptographic dependency. See the [changelog](https://github.com/Nodesify/astria/blob/v1.5.0/CHANGELOG.md) for the release record.

After publication:

```bash
npm install -g @nodesify/astria@1.5.0
astria update .
astria doctor
```

Restart existing MCP processes to load the updated native binding. The [1.5.0 documentation](/docs/intro) is available alongside older snapshots in the version menu.
