**1.0.10** is a one-fix release: it gets astria onto the official MCP Registry, which 1.0.9 reached npm for but could not list. Install or upgrade with `npm install -g @nodesify/astria`.

<!-- truncate -->

## What happened

The registry publish failed with a 403: the GitHub OIDC grant is `io.github.Nodesify/*` — the org login's case is significant — while `server.json` declared `io.github.nodesify/astria`. Registry validation compares the published package's `mcpName` against the server name exactly, and npm is immutable, so the lowercase name could never validate.

## The fix

Both `server.json` and the package's `mcpName` moved to `io.github.Nodesify/astria`, and the release pipeline gained two hardenings along the way: it waits for npm's CDN to actually serve the new version before publishing to the registry (a just-published version can 404 for a few seconds), and the GitHub Release is created *before* the registry step so a registry rejection can no longer leave a released version with no Release at all.

`io.github.Nodesify/astria` is now listed on the [official MCP Registry](https://registry.modelcontextprotocol.io).
