**1.2.0** ranks callable declarations ahead of vocabulary-sharing prose for behavior questions and removes automatic token-size benchmark output from indexing.

<!-- truncate -->

`astria run` and `astria update` report pipeline facts; retrieval evaluation runs separately. Generated evaluation prompts and output are excluded from the self-corpus graph so they cannot become retrieval evidence. Documentation also removes the obsolete migration command: create a fresh `.astria/` graph rather than migrating `.graphify/` data.

Platform checks document the existing Linux native-runtime requirements and musl limitation instead of presenting packaging checks as proof of native execution. See the [1.2.0 changelog](https://github.com/Nodesify/astria/blob/v1.2.0/CHANGELOG.md) for the recorded ranking measurements and platform details.
